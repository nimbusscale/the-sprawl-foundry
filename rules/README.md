# The Sprawl v1.1 -- Markdown Reference

This is the full text of **The Sprawl v1.1** by Hamish Cameron, converted from the
official PDF into markdown so it can be searched and quoted directly.

**Conventions**

- `<!-- p.70 -->` marks the start of printed book page 70, so any passage can be
  cited back to the physical book.
- Move names are bold: `**act under pressure**`, `**mix it up**`.
- `>` blocks are examples of play and in-fiction colour, not rules.
- Chapter-opening short fiction is collected in `98-chapter-fiction.md` so it
  stays out of rules searches.

**Finding things**

- A basic move (act under pressure, mix it up, hit the street, get the job,
  getting paid) -- `02-basic-moves.md`.
- Character creation, step by step -- `03-preparing-to-play.md`.
- One playbook's moves, gear and directives -- `04-playbook-<name>.md`.
- Harm, armour and the Harm Clock -- `02-basic-moves.md` (the move) and
  `09-running-the-sprawl.md` (how the MC inflicts it).
- Countdown Clocks -- `01-playing-in-the-sprawl.md` (concept) and
  `09-running-the-sprawl.md` (running them).
- Weapon and gear tags, Cred, contacts -- `06-assets.md`.
- Hacking, ICE, matrix moves -- `08-the-matrix.md`.
- Building and running a mission -- `11-missions.md`.
- Changing the rules for your table -- `12-hacking-the-sprawl.md`.

Regenerate with `python3 tools/build.py` from the directory holding the PDF.
